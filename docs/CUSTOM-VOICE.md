# 내가 듣고 싶은 목소리

## 서로 다른 두 기능

| 방식 | 가능한 경험 | 준비물 |
|---|---|---|
| 원본 녹음 듣기 | 실제로 남긴 인사·말을 다시 재생 | 보유한 음성/영상 파일과 사용 권한 |
| 맞춤 AI 목소리로 대화 | 해당 음색으로 새로운 AI 답변을 합성 | 사용 동의·권한 확인, 음성 공급사 승인/기능, 깨끗한 샘플, 합성 서버 |

목소리만 복제해도 그 사람의 기억·생각·인격이 복원되는 것은 아니다. AI 답변의 관계·성격·배경은 별도로 설정해야 한다.

## 친구의 영상

영상에서 음성을 추출하고 친구 한 명만 말하는 구간을 분리할 수 있다. 음악·다른 사람의 겹친 말·잡음이 적을수록 유리하다. 영상 소유와 목소리 합성 동의는 별개다. 친구가 허용한 사용 범위와 해당 제공 업체의 검증 조건을 먼저 확인해야 한다.

ElevenLabs Instant Voice Cloning 공식 문서는 깨끗한 1–2분 샘플을 권장하며 음성에 대한 권리와 동의 확인을 요구한다. Professional Voice Clone은 본인 음성만 직접 생성할 수 있으며, 다른 사람의 동의만으로 대신 생성할 수 있는 상품은 아니다.

- [Instant Voice Cloning](https://elevenlabs.io/docs/eleven-creative/voices/voice-cloning/instant-voice-cloning)
- [다른 사람의 Professional Voice Clone 제한](https://help.elevenlabs.io/hc/en-us/articles/36842751624209-Can-I-create-a-Professional-Voice-Clone-of-someone-else-s-voice)

## 돌아가신 가족의 녹음

녹음에서 음색의 특징을 학습하는 기술은 있지만, 오래된 파일이 있다는 이유만으로 모든 업체에서 합성이 가능한 것은 아니다. 예를 들어 OpenAI custom voices는 자격이 있는 고객과 음성 소유자의 정해진 동의 녹음을 요구한다. 유가족이 보관 중인 과거 녹음만 있는 경우 해당 업체가 수락하는 동의·권한 절차를 따로 확인해야 한다. 동의 음성을 합성하거나 다른 사람이 대신 읽어 검증을 통과시키면 안 된다.

제품에서는 ‘가족이 실제로 남긴 말’과 ‘가족과 닮은 음성으로 새로 생성한 AI 대화’를 분명히 구분한다. 원본 녹음을 먼저 들을 수 있는 기능은 합성 승인 여부와 독립적으로 설계할 수 있다.

- [OpenAI custom voices](https://developers.openai.com/api/docs/guides/custom-voices)

## 향후 전체 통화 연결 흐름

1. 기본 목소리 / 내 음성 자료 선택.
2. 원본 재생용인지, 새로운 말을 합성할 용도인지 선택.
3. 누구의 음성인지와 허용 범위 확인. 파일 전송 전에 처리 업체·보관·삭제 방식을 안내.
4. 음성 또는 영상 가져오기 → 한 명이 말하는 구간 선택 → 잡음·길이·언어 품질 확인.
5. 공급사가 요구하는 동의·본인 검증 또는 개별 사례 승인.
6. 짧은 문장으로 합성 미리 듣기 → 승인된 목소리를 캐릭터에 연결.
7. 개인용 기본값, 원본/합성 구분, 사용 중단·원본 삭제·공급사 음성 삭제 및 검증 실패 처리.

2026-09-16부터 녹음·음성 파일 보관과 원본 재생을 구현했다. ElevenLabs 복제 생성·새 문장 합성·업체 삭제 연동 코드를 추가했으며 실제 계정 검증은 아직 하지 않았다. 영상 음성 추출, 구간 편집, 업체 추가 검증 완료 후 상태 동기화, 복제 음성을 실제 전화에 연결하는 작업은 남아 있다.

공식 문서 확인일: 2026-09-15. 위 내용은 제공 업체의 기능·조건에 관한 설명이며 특정 녹음의 법적 사용 가능 여부를 확정하지 않는다.


## 2026-09-16 구현과 검증

### 지금 사용하기
- 전화 만들기 → 목소리 단계 또는 마이 → 내가 듣고 싶은 목소리.
- 기본 데모에서는 실제 설치된 한국어 Speech voice identifier를 선택한다. 하나만 설치돼 있으면 하나만 표시한다. 이름만 다른 5개 데모 음성은 제거했다.
- 선택한 ID를 초안과 예약의 선택 필드 voiceChoice에 저장하고 데모 대화에서도 사용한다. 기존 저장 키와 voice 필드는 유지한다. 선택한 음성이 없는 기기에서는 안내하고 다른 음성으로 몰래 대체하지 않는다.
- pitch=1, rate=0.94로 인위적인 음높이 변조를 없앴다. 미리 듣기 대사를 구어체로, 서버 음성 지시를 늦은 밤 자연스러운 대화 리듬으로 수정했다. 기기 TTS 자체의 음질 한계는 남는다.
- 직접 녹음(최대 2분), 취소, 파일 추가(12MB 이하, 최대 10개), 원본 재생/정지, 삭제 확인을 구현했다.
- 웹: IndexedDB Blob 저장, 파일 재생 형식 확인, 생성 URL 정리. 네이티브: 앱 documentDirectory에 복사하고 AsyncStorage에 메타데이터 보관. 개인 녹음은 Git에 포함하지 않는다.
- 녹음 중 화면을 떠나면 녹음을 중지하고 저장하지 않는다. 앱이 백그라운드로 가면 중지·보관한다. 브라우저 종료/OS 강제 종료에서는 진행 중 녹음 보관을 보장하지 않는다.

### 계정 연결 후 검증할 기능
1. README의 실제 서버 인증 설정(Supabase)을 준비한다. 현재 서버의 실제 모드는 Twilio/OpenAI 설정도 필요하다. 음성 스튜디오 단독 로그인 모드는 아직 분리하지 않았다.
2. 서버 환경 파일에 ELEVENLABS_API_KEY를 설정한다. 공개 Expo 환경 변수나 Git에 키를 넣지 않는다.
3. 앱 실제 모드에서 로그인하고 마이 → 음성 서비스 연결 확인을 누른다. 데모 서버는 임시 세션이므로 외부 음성 생성 요청을 허용하지 않는다.
4. 사용 권한과 ElevenLabs 전송 동의 후 원본의 ‘이 음성으로 새 대사 만들기’를 누른다. 로컬 보관만으로 외부 전송되지 않는다.
5. API requires_verification=false로 반환된 목소리만 새 문장 합성이 가능하다. 확인 값이 없거나 true이면 대기 상태로 두며 인증을 우회하지 않는다. 추가 검증 상태의 자동 갱신은 미구현이다.
6. 입력 문장(500자 이하)을 저장된 provider voice ID로 합성한다. 한국어 multilingual_v2, stability 0.4 / similarity 0.75 / style 0.15 / speed 0.95를 시작값으로 사용하며 실제 청취 조정이 필요하다.
7. 업체 목소리 삭제와 기기 원본 삭제는 별도 동작이다. 삭제 실패 시 업체 메타데이터를 유지해 재시도할 수 있다.

현재 맞춤 목소리 합성은 음성 스튜디오의 문장 미리 듣기까지 연결했다. Twilio 실시간 통화에 복제 목소리를 적용하지 않았으며, 기존 전화는 OpenAI Realtime 목소리를 사용한다. 외부 생성 결과를 확인하지 못한 네트워크 오류가 나면 재시도 전 업체 계정과 목록을 확인해야 한다. 서버의 원본 전송은 메모리에서 처리하며 파일로 저장하지 않는다. 업체 보관·계정 정책은 별도로 적용된다.

### 검증 범위
- 앱 타입 검사와 테스트 18개, 서버 타입 검사와 테스트 12개 통과.
- 실제 브라우저에서 기기 한국어 음성 1개(Microsoft Heami)를 확인하고 선택/미리 듣기/정지를 확인했다.
- 테스트용 WAV 추가, 새로고침 후 보존, 원본 재생 상태, 테스트 원본 삭제를 확인했다. 개인 녹음을 테스트에 쓰거나 전송하지 않았다.
- 서버 테스트는 외부 호출을 모의 응답으로 대체하여 인증/설정/전송 동의/소유자 격리/검증 대기/합성 voice ID/삭제를 확인했다.
- 실제 마이크 녹음과 iOS·Android 기기, 외부 복제 음질·요금·계정 승인은 미검증이다. 음질 개선 완료라고 주장하지 않는다.

공식 API: [복제 생성](https://elevenlabs.io/docs/api-reference/voices/ivc/create), [새 문장 합성](https://elevenlabs.io/docs/api-reference/text-to-speech/convert).
